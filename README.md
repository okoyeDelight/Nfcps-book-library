# NFCPS BOOK LIBRARY

> Christ, the Therapy for All.

Official Digital Library of the National Fellowship of Christian Pharmacy Students (NFCPS), UNIZIK Chapter.

## Live preview

https://nfcps-book-library-c2ma7y.v2.appdeploy.ai/

## Current build

- Interactive 3D physical-book collection
- Automated physical-book reservations with no admin approval
- Self-confirmed collection and return
- 30-day lending period and one automatic renewal
- Public Reserved / Borrowed / Available status with expected return date
- Daily circulation scheduler for reservation expiry, due-soon notices and overdue follow-up
- WhatsApp Business reminder integration prepared for secure server-side credentials
- 600-book free Christian e-book browse target
- Curated NFCPS Christian recommendations

See `docs/circulation-automation.md` for the circulation and WhatsApp reminder workflow.
