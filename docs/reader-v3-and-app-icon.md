# Reader V3 and installed-app icon

The NFCPS Book Library reading experience now behaves like a dedicated novel reader instead of a single uncontrolled scroll.

## Reader V3

- Page-by-page reading with Next / Previous controls and swipe navigation.
- Saved reading progress and Continue Reading.
- Font size, font family, line spacing, page colour, text tone and paragraph alignment controls.
- Bookmarks.
- Text highlighting with multiple highlight colours.
- Private reading notes attached to highlighted passages.
- Contents, bookmarks and notes drawer.
- Automatic offline cache after the first successful open.
- Direct download control inside the reader.
- Current reading position continues feeding NFCPS Moments excerpts.

## Free e-books

The public-domain Gutenberg shelf only displays reader-ready titles. Every displayed free e-book exposes both **Read in NFCPS** and **Download**. Free recommended classics can also open in the NFCPS reader. Modern copyrighted recommendations only point to legitimate/legal copy options.

## Installed app identity

The PWA manifest uses the uploaded NFCPS logo as the primary icon. A mask-safe icon wrapper places the same NFCPS logo on the NFCPS dark-green/gold branded background so Android launchers do not fall back to a plain white-looking icon.
