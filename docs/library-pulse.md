# NFCPS Library Pulse

The live Physical Library V2 now includes a privacy-safe Library Pulse panel.

## What it shows

- Reading now: current borrowed copies.
- Due this week: books expected back within seven days.
- Waiting: current physical-book waitlist demand.
- Returns logged: recent completed return records.
- Most Requested Lately: a ranking based on current requests, recent closed circulation records and active waitlist demand.
- Returning This Week: due dates plus current waitlist pressure for each returning title.
- Recent Activity: reservation, borrowing, return and reservation-expiry events.

## Privacy rule

The public insights endpoint never returns borrower names or phone numbers. Public activity is limited to book identity, circulation state, due/return timing, waitlist counts and aggregate demand signals.

## Circulation rules retained

- 24-hour reservation window.
- 30-day loan period after collection is confirmed.
- Maximum two active physical books/reservations per member phone number.
- Overdue members cannot request another physical book until the overdue copy is returned.
- One automatic 30-day renewal when no member is waiting.
- Automatic waitlist promotion when a copy is returned or a reservation expires.
- Free NFCPS UNIZIK LIBRARY push reminders and calendar backup.
