# Tests

## Test 1 - Open a real ebook and read with compact controls [sanity]
Viewport: mobile (375x667)
Covers: 44-title locally-owned NFCPS core shelf, /api/reader/book, validated text parsing, page navigation, compact reader controls
Description: Verifies the primary Read workflow always has a substantial local shelf and never opens a visually empty book.

Steps:
1. Open Read, confirm All Books contains at least 44 locally-owned titles, then open The Pursuit of God
2. Confirm actual readable book text is visible below the opening title instead of an empty page
3. Swipe or advance to another page, tap the page to reveal controls, then open Themes & Settings

Expected: A real readable passage is visible, page navigation changes the reading position, and compact Contents, Notes, Themes & Settings and progress controls are available without covering the page permanently.

## Test 2 - Core shelf survives catalogue outage
Viewport: mobile (375x667)
Covers: local 44-title catalogue, /api/ebooks/catalog failure guardrail, search, category filters
Description: Verifies external catalogue availability can never collapse NFCPS One back to a tiny or blank e-book shelf.

QA Faults:
```json
[
  {
    "method": "GET",
    "path": "/api/ebooks/catalog",
    "status": 500,
    "body_json": { "error": "simulated_catalog_outage" }
  }
]
```

Steps:
1. Open Read while catalogue enrichment requests fail and confirm All Books remains populated
2. Browse Prayer, Bible, Theology, Devotional, Growth, Missions and Sermons, then search for Power Through Prayer
3. Open the matching title and return to All

Expected: The locally-owned NFCPS shelf remains populated, Power Through Prayer can be found from the local core, category filters retain useful books, and no reconnecting or engineering-status placeholder replaces the collection.

## Test 3 - Reader preferences and annotations persist
Viewport: mobile (375x667)
Covers: reader page/continuous modes, themes, typography, progress persistence, bookmarks, highlights, notes, local reader state
Description: Verifies Apple Books-inspired reading controls change durable reading state rather than acting as decorative UI.

Steps:
1. Open a known book, reveal Themes & Settings, switch to Continuous reading, change the theme and increase text size
2. Return to the text, save a bookmark and create a highlight or note from selected text
3. Close the book, reopen it and inspect the reading controls and Notes panel

Expected: The reading mode, theme, text size, progress, bookmark and saved annotation remain available after reopening the book.

## Test 4 - Existing Watch and Library flows remain intact
Viewport: mobile (375x667)
Covers: Watch navigation, physical Library navigation, five-tab app shell, existing personal reading state
Description: Guards against the Read reliability work disrupting the rest of NFCPS One.

Steps:
1. Leave Read using the five-tab navigation and open Watch
2. Return and open Library, then browse the physical collection
3. Return to Read and reopen the most recently read e-book

Expected: Watch and physical Library still open normally, the shared navigation remains aligned, and the last-read e-book can be resumed with its saved progress.
